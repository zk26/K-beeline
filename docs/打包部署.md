# 打包部署指南

把 K-Beeline 构建成一个可以发给任何人的安装程序 `KBeelineSetup.exe`。

## 前置条件（只在打包机上需要）

| 工具 | 说明 |
|---|---|
| Python 3.12 (64位) | 构建环境 |
| Inno Setup 6 | 制作安装程序，`winget install JRSoftware.InnoSetup` |
| Edge 浏览器 | 运行冒烟测试时需要 |

> 最终用户的机器上**什么都不需要**（Edge 除外，Win10/11 自带）。

## 一次性准备

```powershell
cd K-beeline
python -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple/
```

> 本机网络访问 PyPI 慢，务必用国内镜像。PySide6 体积大，如反复超时可用 curl 断点续传下载 wheel 后本地安装。

## 构建步骤

### 第 1 步：构建 exe

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1
```

产物：`dist\KBeeline\`（内含 `KBeeline.exe` + 全部依赖 + assets 资源）

**验证**：双击 `dist\KBeeline\KBeeline.exe` 能正常打开界面，且驱动检测为 ✓。

### 第 2 步：构建安装程序

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" scripts\installer.iss
```

产物：`Output\KBeelineSetup.exe` —— **这就是要发出去的文件**。

## 发给最终用户

1. 把 `KBeelineSetup.exe` 发给对方（微信/网盘/U盘均可）
2. 对方双击安装（无需管理员权限），桌面出现软件图标
3. 对方按「使用说明.md」操作即可

用户机器上的数据位置：`%LOCALAPPDATA%\KBeeline\`（配置、日志、驱动缓存、IP记录）。

## 版本更新流程

1. 修改 `app\ui\main_window.py` 中的 `APP_VERSION` 与 `scripts\installer.iss` 中的 `MyAppVersion`
2. 重新执行第 1、2 步
3. 新安装包覆盖安装即可（用户数据保留）

## Edge 驱动策略（重要）

安装包内置了一个兜底驱动（`assets\drivers\msedgedriver.exe`），但**软件真正的保障是启动时的自动更新**：

```
启动 → 读取本机Edge版本 → 缓存命中? → 直接用
                          ↓ 未命中
              微软CDN查询匹配版本 → 自动下载到缓存
                          ↓ 网络失败
                  内置兜底驱动（大版本一致才用）
                          ↓ 也不匹配
              Selenium Manager 运行时自动解析
```

- 用户 Edge 每次自动升级后，软件下次启动会自动补齐新驱动，**不需要重新发安装包**
- 只有你希望缩短首次启动的驱动下载时间时，才需要在打包前更新 `assets\drivers\msedgedriver.exe` 为当前最新版

## 常见问题

- **PyInstaller 报缺模块**：在 `build_exe.ps1` 中追加 `--hidden-import 模块名`
- **杀毒软件误报**：onedir 模式误报率低；如有误报加白名单即可，不要换 onefile（更容易误报）
- **安装包体积**：约 200MB（Qt 库占大头），属正常水平
