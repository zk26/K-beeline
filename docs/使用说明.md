# K-Beeline 自动化助手 · 使用说明

## 安装

1. 双击 `KBeelineSetup.exe`
2. 一路"下一步"即可（不需要管理员权限，装在你自己的用户目录下）
3. 桌面出现「K-Beeline 自动化助手」图标，双击启动

**系统要求**：Windows 10/11（64位），已安装 Microsoft Edge 浏览器（Win10/11 一般自带）。

## 第一次使用（3 步）

### 第 1 步：准备账号表

- 点击「下载模板」，把 `Autouer.xlsx` 模板保存到好找的位置（如桌面）
- 用 Excel/WPS 打开，在**学号**列填入账号（每行一个，纯数字学号即可，软件会自动加 GUC 前缀）
- **填完务必关闭 Excel/WPS**，否则文件被占用无法处理

### 第 2 步：选择模式与开关

| 模式 | 做什么 | 结果写回 |
|---|---|---|
| **发帖模式** | 登录 → 进芯泉子 → 发一条带图帖子 | 状态/密码/位置/IP |
| **激活模式** | 登录 → 重置密码 → 进芯泉子 | 状态/密码/时间 |

功能开关：
- **使用代理IP池（一号一IP）**：每个账号换一个 IP，防止同 IP 多账号被封。**发帖模式建议开启**；代理不可用时会自动回退本地 IP。
- **使用虚拟定位**：每次登录随机定位到全国某城市。

### 第 3 步：开始任务

点击「开始任务」，然后不用管了：
- 每个账号会自动开一个浏览器窗口操作，**请勿手动干预这些窗口**
- 进度条、成功/失败计数、实时日志都在界面上
- 随时可以点「停止」（当前账号会被中断，已完成的不会丢）

完成后会弹出统计汇总，所有结果已经写回账号表的**备注**列。

## 关于浏览器驱动（你完全不用操心的事）

软件每次启动时都会自动检查：
- 你的 Edge 是什么版本 → 自动下载对应版本的驱动
- Edge 以后自动升级了也没关系，下次启动软件会自动配好新驱动

界面顶部「浏览器驱动」区显示当前状态，正常为绿色 ✓。也可以手动点「检查/更新驱动」。

## 备注列格式（结果怎么看）

**发帖模式**：`2.发帖成功-已重置[A123456a]-北京-112.10.33.5`
- 开头数字即状态码：`2`=发帖成功、`1`=密码错误、`3`=登录成功但发帖失败、`4`=账号不存在、`5`=其他错误、`7/8/9`=页面导航失败

**激活模式**：`1.激活成功-密码重置成功[A123456a]-2026-09-01 21:30:00`
- `1`=激活成功、`2`=密码错误、`3`=账号错误、`5`=其他错误

## 常见问题

**Q: 提示"未检测到 Edge 浏览器"？**
安装 Microsoft Edge 后重启软件。Edge 下载：https://www.microsoft.com/edge

**Q: 提示"账号表被占用"？**
关闭所有打开该文件的 Excel/WPS。软件也会询问是否帮你强制关闭，选"是"即可。

**Q: 处理中途浏览器窗口卡住？**
直接点「停止」，然后重新「开始任务」。已写回备注的账号不会丢；想跳过已处理账号，把已处理行从表里删掉再跑。

**Q: 代理获取失败/全是本地IP？**
代理池是付费服务，先确认主代理池API还有余额（高级设置里能看到 API 地址）。代理不可用时软件会自动用本地 IP 继续，并在日志里说明。

**Q: 日志在哪里？**
`%LOCALAPPDATA%\KBeeline\logs\` 目录下，按日期命名。出问题时把当天的日志文件发给维护人。

## 高级设置（一般不用动）

「高级设置」里可以调整：目标站点、账号前缀、尝试密码列表、重置密码、代理池 API、等待时长、高德 API Key。改动后自动保存到 `%LOCALAPPDATA%\KBeeline\config.json`。
